🎯 TalentRadar — система обнаружения потенциала

Мы ищем человека, а не заявку.

TalentRadar — это интеллектуальная система отбора талантливых кандидатов. Вместо скучной фильтрации резюме она раскрывает потенциал каждого через адаптивный диалог и оценивает не только то, кто кандидат сейчас, но и куда он движется.

🚀 Что умеет система

Адаптивное интервью — Telegram-бот задаёт умные вопросы, подстраиваясь под каждого кандидата
Оценка траектории роста — система смотрит на динамику, а не только на текущий уровень
Детектор ИИ-текста — определяет, написал ли кандидат эссе сам или использовал ChatGPT
Прозрачный дашборд — комиссия видит не просто баллы, а объяснение каждой оценки

🧠 Как работает оценка кандидата
Каждый кандидат получает итоговый балл от 0 до 100, который складывается из 4 компонентов:
КомпонентВесОписание🏆 Лидерский потенциал34%Анализ ответов на вопросы о лидерстве и инициативе📈 Траектория роста28%Динамика достижений во времени✍️ Аутентичность21%Оригинальность текста, отсутствие ИИ-генерации🎯 Релевантность17%Соответствие требованиям программы
Пример: 83 балла = лидерский потенциал +34, траектория роста +28, аутентичность +21
Комиссия всегда видит расшифровку — никакого "чёрного ящика".

🛠️ Быстрый старт
1. Клонируй репозиторий
bashgit clone https://github.com/твой-username/talent-radar.git
cd talent-radar
2. Настрой переменные окружения
bashcp .env.example .env
# Открой .env и вставь свои ключи
Содержимое .env:
TELEGRAM_TOKEN=твой_токен_от_BotFather
ANTHROPIC_API_KEY=твой_ключ_от_Anthropic
3. Запусти Telegram-бот
bashcd bot
pip install -r requirements.txt
python main.py
4. Запусти Backend
bashcd backend
pip install -r requirements.txt
python app.py
5. Открой дашборд
Открой файл frontend/index.html в браузере — и дашборд готов!
