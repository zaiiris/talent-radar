#  API.md — Документация Backend API TalentRadar

Этот документ описывает все маршруты backend-сервера TalentRadar.
Проще говоря — это "меню" того, что умеет наш сервер.

---

##  Базовый URL

```
http://localhost:8000
```

После деплоя на Railway/Render адрес будет другим — обновить здесь.

---

##  Все маршруты одним взглядом

| Метод | Маршрут | Кто использует | Описание |
|---|---|---|---|
| GET | `/` | Все | Проверка что сервер работает |
| POST | `/candidate` | Telegram-бот | Создать нового кандидата |
| GET | `/candidate/{id}` | Дашборд | Получить данные одного кандидата |
| POST | `/score/{id}` | Backend (авто) | Запустить оценку кандидата |
| GET | `/candidates` | Дашборд | Список всех кандидатов с баллами |
| GET | `/shortlist` | Дашборд | Только кандидаты в шортлисте |
| POST | `/shortlist/{id}` | Дашборд | Добавить кандидата в шортлист |
| DELETE | `/shortlist/{id}` | Дашборд | Убрать кандидата из шортлиста |

---

## 📖 Подробное описание каждого маршрута

---

###  GET `/`
**Что делает:** проверяет что сервер запущен и работает.

**Запрос:**
```
GET http://localhost:8000/
```

**Ответ:**
```json
{
  "status": "ok",
  "message": "TalentRadar API работает"
}
```

---

###  POST `/candidate`
**Что делает:** создаёт нового кандидата в базе после того как бот закончил интервью.

**Кто вызывает:** Telegram-бот автоматически после последнего вопроса.

**Что отправляем:**
```json
{
  "name": "Айгерим Касымова",
  "telegram_id": "123456789",
  "answers": {
    "q1": "Я организовала волонтёрский проект в школе...",
    "q2": "Три года назад я не умела публично выступать...",
    "q3": "Моя цель — развивать образование в регионах..."
  },
  "essay": "Текст эссе кандидата здесь..."
}
```

**Что получаем:**
```json
{
  "id": "abc123",
  "name": "Айгерим Касымова",
  "status": "created",
  "message": "Кандидат создан, оценка запущена"
}
```

---

###  GET `/candidate/{id}`
**Что делает:** возвращает полные данные одного кандидата с баллами.

**Кто вызывает:** дашборд когда комиссия кликает на карточку кандидата.

**Запрос:**
```
GET http://localhost:8000/candidate/abc123
```

**Что получаем:**
```json
{
  "id": "abc123",
  "name": "Айгерим Касымова",
  "total_score": 86,
  "scores": {
    "leadership": 90,
    "growth": 85,
    "authenticity": 95,
    "relevance": 70
  },
  "explanation": "86 баллов — сильный кандидат. Высокий лидерский потенциал и аутентичность.",
  "ai_flag": false,
  "in_shortlist": false
}
```

---

### 📊 POST `/score/{id}`
**Что делает:** запускает ИИ-анализ и подсчёт баллов для кандидата.

**Кто вызывает:** вызывается автоматически после создания кандидата.

**Запрос:**
```
POST http://localhost:8000/score/abc123
```

**Что получаем:**
```json
{
  "id": "abc123",
  "status": "scored",
  "total_score": 86,
  "scores": {
    "leadership": 90,
    "growth": 85,
    "authenticity": 95,
    "relevance": 70
  }
}
```

---

### 📋 GET `/candidates`
**Что делает:** возвращает список ВСЕХ кандидатов, отсортированных по баллам.

**Кто вызывает:** дашборд при загрузке главной страницы комиссии.

**Запрос:**
```
GET http://localhost:8000/candidates
```

**Что получаем:**
```json
{
  "total": 3,
  "candidates": [
    {
      "id": "abc123",
      "name": "Айгерим Касымова",
      "total_score": 86,
      "ai_flag": false,
      "in_shortlist": true
    },
    {
      "id": "def456",
      "name": "Данияр Сейткали",
      "total_score": 74,
      "ai_flag": false,
      "in_shortlist": false
    },
    {
      "id": "ghi789",
      "name": "Мадина Ержанова",
      "total_score": 61,
      "ai_flag": true,
      "in_shortlist": false
    }
  ]
}
```

---

###  GET `/shortlist`
**Что делает:** возвращает только кандидатов которых комиссия добавила в шортлист.

**Запрос:**
```
GET http://localhost:8000/shortlist
```

**Что получаем:**
```json
{
  "total": 1,
  "candidates": [
    {
      "id": "abc123",
      "name": "Айгерим Касымова",
      "total_score": 86
    }
  ]
}
```

---

### ➕ POST `/shortlist/{id}`
**Что делает:** добавляет кандидата в шортлист.

**Кто вызывает:** дашборд когда комиссия нажимает кнопку "Добавить в шортлист".

**Запрос:**
```
POST http://localhost:8000/shortlist/abc123
```

**Что получаем:**
```json
{
  "id": "abc123",
  "status": "added_to_shortlist"
}
```

---

###  DELETE `/shortlist/{id}`
**Что делает:** убирает кандидата из шортлиста.

**Запрос:**
```
DELETE http://localhost:8000/shortlist/abc123
```

**Что получаем:**
```json
{
  "id": "abc123",
  "status": "removed_from_shortlist"
}
```

---

##  Переменные окружения для backend

```
ANTHROPIC_API_KEY=твой_ключ   # для ИИ-анализа
DATABASE_URL=sqlite:///./talentradar.db   # база данных
```

##  Коды ошибок

| Код | Значение |
|---|---|
| 200 | Всё хорошо |
| 404 | Кандидат не найден |
| 422 | Неверный формат данных |
| 500 | Ошибка сервера |
