# SCORING.md — Система оценки кандидатов TalentRadar

---

## Главный принцип

> Мы оцениваем не кем ты был, а кем ты становишься.

---

## Итоговый балл

Каждый кандидат получает балл от **0 до 100**.
```
Итоговый балл = (Лидерство × 0.34) + (Рост × 0.28) + (Аутентичность × 0.21) + (Релевантность × 0.17)
```

---

## 4 компонента оценки

### 1. Лидерский потенциал — 34%

Анализ ответов в боте через Claude AI. Оцениваем способность брать инициативу и вести за собой.

| Баллы | Описание |
|---|---|
| 85–100 | Яркие примеры лидерства, конкретные результаты |
| 60–84 | Есть примеры, но без конкретики |
| 35–59 | Общие слова, нет реальных примеров |
| 0–34 | Нет признаков лидерского мышления |

---

### 2. Траектория роста — 28%

Оцениваем динамику развития, а не текущий уровень.

| Баллы | Описание |
|---|---|
| 85–100 | Явный резкий рост, конкретные точки прорыва |
| 60–84 | Стабильный рост с примерами |
| 35–59 | Небольшой рост или стагнация |
| 0–34 | Нет признаков развития |

---

### 3. Аутентичность — 21%

Определяем написал ли кандидат эссе сам или использовал ИИ.

| Статус | Описание |
|---|---|
| Высокая | Текст явно написан человеком |
| Под вопросом | Признаки ИИ есть, но не критично |
| Флаг ИИ | Высокая вероятность генерации |

---

### 4. Релевантность — 17%

Насколько кандидат подходит под требования inVision U.

| Баллы | Описание |
|---|---|
| 85–100 | Полное совпадение с профилем программы |
| 60–84 | Хорошее совпадение |
| 35–59 | Частичное совпадение |
| 0–34 | Профиль не соответствует программе |

---

## Пример расчёта

**Кандидат: Айгерим К.**

| Компонент | Балл | Вес | Итог |
|---|---|---|---|
| Лидерский потенциал | 90 | 34% | 30.6 |
| Траектория роста | 85 | 28% | 23.8 |
| Аутентичность | 95 | 21% | 19.95 |
| Релевантность | 70 | 17% | 11.9 |
| **Итого** | | | **86.25** |

```python
WEIGHTS = {

    "authenticity": 0.21,
    "relevance": 0.17
}
```
